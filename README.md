# \# Public NYISO Power Market Data Analysis

# 

# \## Overview

# 

# This project analyzes public NYISO market and load data to examine the relationship between electricity demand, calendar conditions, historical price behavior, and zonal wholesale power prices.

# 

# It is an independent educational analysis using only publicly available data, personal equipment, personal accounts, and personal time. It does not use NYISO nonpublic information, systems, internal models, work product, confidential market information, or information obtained through employment.

# 

# \## Project Objective

# 

# The initial objective is to develop a reproducible analytical workflow for examining hourly NYISO zonal day-ahead Locational-Based Marginal Prices (LBMPs), with an initial focus on Zone J and Zone G.

# 

# The project will begin with exploratory data analysis and transparent historical-average benchmarks. Later phases may assess whether public load, calendar, historical price, and weather variables improve forecast accuracy or help explain day-ahead versus real-time price differences.

# 

# This is not a live trading strategy and does not make claims regarding profitability.

# 

# \## Research Questions

# 

# \- How do NYISO zonal day-ahead prices vary by hour, weekday, month, and season?

# \- What is the relationship between publicly available load data and zonal day-ahead prices?

# \- How do price patterns differ between Zone J and Zone G?

# \- Can transparent public-data models improve on a historical-average benchmark?

# \- Under what conditions do day-ahead and real-time prices diverge?

# 

# \## Proposed Methodology

# 

# 1\. Obtain and document only public market and load data.

# 2\. Validate timestamps, time zones, zones, units, duplicates, and missing values.

# 3\. Conduct exploratory analysis of price and load patterns.

# 4\. Build a historical-average benchmark by hour, weekday, and month.

# 5\. Test transparent models such as linear regression and tree-based regression.

# 6\. Use chronological train, validation, and out-of-sample test periods.

# 7\. Evaluate results using MAE, RMSE, directional accuracy, and error analysis by time period.

# 8\. Clearly document limitations, assumptions, and data-quality issues.

# 

# \## Planned Datasets

# 

# \- Public NYISO day-ahead zonal LBMP data.

# \- Public NYISO real-time zonal LBMP data, added after timestamp and aggregation validation.

# \- Public NYISO actual load data.

# \- Public NYISO load-forecast data, only if original publication timing can be verified.

# \- Self-generated calendar variables.

# \- Public weather data, potentially added in a later phase.

# \- Public ancillary-services data, potentially added for a later battery-storage project.

# \## Limitations

# 

# \- Public data cannot capture all generator, transmission, fuel, weather, dispatch, and operational drivers of market outcomes.

# \- Public data may have timing, aggregation, coverage, and revision limitations.

# \- A relationship observed in historical data does not establish causation.

# \- Historical forecast performance does not demonstrate profitability or suitability for trading.

# \- Any data whose public status or publication timing is unclear will not be used.
