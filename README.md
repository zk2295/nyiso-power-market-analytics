# Public Power Market Data Analysis

## Overview

This repository contains independent educational analyses of publicly available U.S. power-market data. The work focuses on electricity-market fundamentals, including load, wholesale prices, calendar patterns, and energy-system analytics.

## Initial Project

The first project will examine the relationship between public NYISO load and market-price data, with an initial focus on zonal day-ahead prices and day-ahead versus real-time price differences.

The project will begin with exploratory data analysis and simple benchmark models before evaluating more advanced forecasting approaches.

## Planned Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter notebooks

## Data and Confidentiality Notice

This is an independent personal educational project. It uses only publicly available data, personal equipment, and personal time.

It does not use NYISO systems, nonpublic information, internal models, work product, confidential market information, or any information obtained through employment.
