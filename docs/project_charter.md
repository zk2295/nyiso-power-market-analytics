\# Project Charter



\## Working Title

Public NYISO Power Market Data Analysis



\## Business Question

What public variables are associated with NYISO zonal day-ahead wholesale electricity prices and day-ahead versus real-time price differences?



\## Initial Scope

\- Market: NYISO

\- Geography: Begin with Zones J and G

\- Time frequency: Hourly

\- Initial target: Day-ahead LBMP and day-ahead versus real-time LBMP spread

\- Initial features: Hour, weekday, month, holiday, historical price lags, and public load data



\## Methodology

1\. Download and validate public data.

2\. Conduct exploratory analysis.

3\. Establish a simple historical-average benchmark.

4\. Test transparent forecasting models.

5\. Evaluate results using an out-of-sample period.

6\. Document limitations and avoid claims that exceed the evidence.



\## Planned Outputs

\- Reproducible Python data pipeline

\- Exploratory data analysis notebook

\- Forecasting / spread-analysis notebook

\- Figures and summary tables

\- README and methodology documentation



\## Data and Confidentiality Boundary

This project will use only public data, personal equipment, personal accounts, and personal time. It will not use NYISO nonpublic information, systems, models, work product, or knowledge obtained through employment.
